# ADR-002: своя таблица вместо TanStack Table

## Контекст

Нужны сортировка, фильтр, выделение строки и формат бюджета. На этапе 04 бандл ≤200 КБ gzip.

## Решение

Нативный `<table>` + чистые функции `filterAggregates` / `sortAggregates`.

## Альтернативы

- **TanStack Table.** Гибкий headless API. Лишний вес и API, который не нужен для 47 строк.
- **AG Grid / MUI DataGrid.** Прямо запрещены ТЗ как UI-библиотеки / слишком тяжёлые.

## Последствия

- Сортировка и фильтр тестируются как чистые функции.
- Нет виртуализации — при текущем объёме данных это ок.
- Keyboard navigation на этапе 03 пишем сами.
