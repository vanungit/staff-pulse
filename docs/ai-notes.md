## Этап 01

**Сгенерировано как есть (с правками по стилю проекта):**

- Каркас Vite/TS, `ThemeProvider`, глобальные стили.
- Компонентная нарезка `org-dashboard` / `org-tree` / `status-state`.
- Мок-иерархия Нордлайн (дивизион → отдел → команда).

**Переписано / спроектировано руками:**

- `useCachedQuery` — не стали тащить TanStack Query из-за лимита 200 КБ и чтобы объяснить SWR на собеседовании. Abort + stale time + «не класть в кэш невалидный ответ» — осознанные развилки, не дефолт генерации.
- Zod-обёртка: `ZodError` → одно сообщение, без сырого дампа issues в UI.
- Раскрытие по умолчанию: `depth <= 1`, чтобы были видны отделы, а не только дивизионы.

**Почему не слепой промпт:** генератор первым делом предлагает MUI/react-query/Ant. Оба пункта в ТЗ запрещены или дорого стоят в бандле.
