# Заметки: AI в разработке

Пишем сразу, не постфактум. Пойдёт в README на этапе 04.

## Этап 01

**Сгенерировано как есть (с правками по стилю проекта):**

- Каркас Vite/TS, `ThemeProvider`, глобальные стили.
- Компонентная нарезка `org-dashboard` / `org-tree` / `status-state`.
- Мок-иерархия Нордлайн (дивизион → отдел → команда).

**Переписано / спроектировано руками:**

- `useCachedQuery` — не стали тащить TanStack Query из-за лимита 200 КБ и чтобы объяснить SWR на собеседовании. Abort + stale time + «не класть в кэш невалидный ответ» — осознанные развилки, не дефолт генерации.
- Zod-обёртка: `ZodError` → одно сообщение, без сырого дампа issues в UI.
- Раскрытие по умолчанию: `depth <= 1`, чтобы были видны отделы, а не только дивизионы.

**Почему не слепой промпт:** генератор первым делом предлагает MUI/react-query/Ant. Оба пункта в ТЗ запрещены или дорого стоят в бандле.

## Этап 02

**Сгенерировано:** вёрстка таблицы, toolbar, split-view через `matchMedia`.

**Переписано руками:**

- `aggregateOrgTree` — post-order, взвешивание по headcount. Черновик генерации брал среднее по узлам (`sum(perf)/count`); это ломает смысл метрики. Тест «10×100 + 90×0 = 10, не 50» написан специально как контракт.
- Сортировка: одинарный клик задаёт колонку, двойной — меняет направление. Не toggle по каждому клику, как обычно делают таблицы.

**Не стали делать:** TanStack Table / виртуализацию — 47 строк, бюджет бандла.

## Этап 03

**Сгенерировано:** каркас WS-хука, индикатор, collapse на CSS grid.

**Переписано руками:**

- `patchAggregates` + тест «инкремент = полный пересчёт». Генерация норовила вызвать `aggregateOrgTree` на всё дерево после каждого кадра — прямо против ТЗ.
- Backoff и `onPatch` через ref, чтобы эффект сокета не переподключался на каждый рендер.
- Fade только у изменённого узла, не у всей цепочки предков: иначе корень мигал бы каждые 2.5с.

**Почему WebSocket, не поллинг:** меньше лишних запросов, явный контракт патча для `docs/data-model.md`.

## Этап 04

**Сгенерировано:** Dockerfiles, nginx gzip + `/api` + `/ws`.

**Переписано руками:** `parseOrgSearch` / `applyOrgSearchFilter`. Не стали звать OpenAI: нет ключа в «одной команде», тот же JSON-фильтр можно подменить LLM позже. Тесты на structured vs fallback обязательны — это то, что будут спрашивать. Первая версия регэкспов с `\w` не видела кириллицу (`эффективностью`) — поймали тестом и заменили на `\p{L}`.

Проверка бандла: `npm run build && npm run check:bundle` (лимит 200 КБ gzip на js+css).
